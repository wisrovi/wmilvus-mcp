Exposed Tools

AI Agent Vector Tools

validate_model_schema

Validates Pydantic model definitions against WMilvus vector rules (FieldVector, metric types, index algorithms).

search_wmilvus_pattern

Searches production design patterns (KNN search, radius range search, bulk ingestion, async client, ghost audit log).

deploy_wmilvus_scaffolding

Deploys a complete production vector application project structure with models, services, and tests.

get_wmilvus_architect_blueprints

Provides complete runnable code reference for every WMilvus feature.

generate_wmilvus_crud

Generates ready-to-run CRUD code snippet for custom Pydantic vector models.

generate_mcp_client_config

Generates JSON client configuration snippets for instant integration with Claude or Antigravity.
