# wmilvus-mcp Documentation

Welcome to the official documentation for **wmilvus-mcp**!

`wmilvus-mcp` is the Model Context Protocol (MCP) server for architecting, validating, scaffolding, and generating code for **WMilvus** vector database applications.

---

## Technical Stack & Author

- **Author**: [William Rodriguez (wisrovi)](https://es.linkedin.com/in/wisrovi-rodriguez)
- **Repository**: [github.com/wisrovi/wmilvus-mcp](https://github.com/wisrovi/wmilvus-mcp)
- **PyPI Package**: [pypi.org/project/wmilvus-mcp](https://pypi.org/project/wmilvus-mcp/)

| Component | Technology |
|-----------|------------|
| Language | Python 3.10+ |
| Protocol | Model Context Protocol (MCP) |
| Server Framework | FastMCP (`mcp.server.fastmcp`) |
| Data Validation | Pydantic 2.x & Python `ast` |
| Code Formatting | `ruff` |
| Testing | `pytest`, Docker, `pytest-cov` |
